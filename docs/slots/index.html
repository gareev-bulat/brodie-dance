How it works

  1. Book a free slot below. It opens a GitHub form; submit it. Up to 3 teams share a slot. A bot confirms within a minute, or tells you it's full.
  2. At your time run npm start and chert dev --agent <your-agent>, then call the shared address on FaceTime.
  3. Release it. Hang up, Ctrl+C in the Chert terminal, wait for Stopped, then ping the next team.

Slots

Can't make your slot? Close your booking issue and it opens back up. Times are US Eastern. Bookings live as issues on seraphimlabs-dev/brodie-starter. Questions: #help or /join in #oh-queue.
